Arch Canvas 0.9.16
=====================================

AWS 아키텍처 다이어그램을 노드 방식으로 그리고, PowerPoint에 "편집 가능한 도형"으로 붙여 넣는 도구입니다.

실행
  Arch Canvas.exe 파일 하나만 있으면 됩니다. 처음 실행하면 같은 폴더에 data 폴더를 만들고 내장 파일을 풀어 놓습니다.
  (WebView2 런타임이 필요합니다. Windows 11에는 기본으로 포함되어 있으며, 없으면 안내 창이 표시됩니다.)

쓰는 법
  - 처음 켜면 빈 캔버스에 "무엇을 그려 볼까요?" 칸이 뜹니다. 만들고 싶은 걸 적고 Enter 를 누르면 말로 그리기가 바로 시작됩니다.
    아래 카드로 [시스템 문서로] · [템플릿에서] · [따라 하기](가이드) · [직접 그리기]를 고를 수도 있습니다.
  - 팔레트와 오른쪽 패널은 떼어 낼 수 있습니다. 맨 위 막대를 끌면 떠 있는 창이 되고, 오른쪽 아래 모서리로 크기를 바꿉니다.
    화면 가장자리에 놓거나, 막대를 두 번 클릭하거나, [붙이기]를 누르면 제자리로 돌아갑니다.
  - 왼쪽 팔레트에서 아이콘·그룹을 캔버스로 끌어다 놓습니다. 클릭하면 화면 가운데에 추가됩니다.
  - 노드 가장자리의 점을 끌어 다른 노드 위에 놓으면 연결선이 생깁니다.
  - 선을 선택하면 양 끝에 손잡이가 생깁니다. 다른 요소에 놓으면 연결 대상이 바뀌고, 빈 곳에 놓으면 그 자리에 끝이 남습니다(한쪽은 요소에 연결).
  - 소속은 화면 위치 그대로입니다. 아이콘은 가운데가 놓인 가장 작은 상자에, 상자는 자기를 완전히 감싸는 가장 작은 상자에 속합니다.
    끄는 동안 들어갈 상자가 테두리로 빛나고 아래에 "→ ○○ 안으로" 안내가 뜹니다. 상자를 끌면 안의 요소도 함께 움직입니다.
  - Auto Scaling group · 보안 그룹 · 스팟 플릿은 "겹치는 상자"입니다. 아무것도 품지 않고, 끌면 테두리만 움직입니다.
    안에 보이는 EC2 는 각자의 서브넷에 속한 채 멤버로 표시됩니다. 다른 상자도 오른쪽 패널에서 [겹치는 상자]로 바꿀 수 있습니다.
  - 상자를 선택한 뒤 모서리로 크기를 조절합니다. 안에 든 것보다 작게는 줄어들지 않습니다.
  - 직각선을 선택하면 가운데 구간에 손잡이가 생깁니다. 끌면 꺾이는 위치가 옮겨지고, 두 번 클릭하면 가운데로 돌아갑니다.
  - 앞뒤 순서: 요소를 오른쪽 클릭해 [맨 앞으로 가져오기 · 앞으로 · 뒤로 · 맨 뒤로 보내기] (Ctrl+] · Ctrl+[ , Shift 와 함께 맨 앞/맨 뒤).
    아이콘·글은 늘 상자보다 앞에, 겹치는 상자(ASG 등)는 담는 상자보다 앞에 그려집니다.
  - 묶기: 여러 개를 선택하고 Ctrl+G. 하나를 클릭해도 함께 선택되고 함께 움직입니다. 풀기는 Ctrl+Shift+G.
    선택한 것을 새 상자 안에 넣으려면 오른쪽 클릭 [새 상자로 감싸기].
  - 잠금: Ctrl+L. 잠근 것은 끌기·화살표·정렬·크기 조절로 바뀌지 않고 자물쇠가 보입니다. 잠근 것을 끌면 화면이 움직입니다.
  - 오른쪽 패널에서 라벨, 그룹 종류, 연결선 스타일(실선·점선, 직선·꺾은선, 화살표)을 편집합니다.
  - 템플릿 메뉴(12종): Region · VPC · AZ 2개, Region · VPC · AZ 3개, 3티어 웹, 3티어 웹 (AZ 3개), 서버리스 API, 정적 사이트, 컨테이너 (ECS), 컨테이너 (EKS),
    하이브리드, 솔루션 구성도 (다크), 솔루션 구성도 (라이트), Connect CV (컨택센터 · Amazon Connect + Contact Lens). 템플릿을 골라도 제안서 컨텍스트와 테마는 유지됩니다.
    "현재 다이어그램을 템플릿으로 저장"을 누르면 data\app\user-templates 에 JSON 으로 저장되고 메뉴에 추가됩니다.
  - 개요도: 빈 곳 오른쪽 클릭 [개요도 새 탭에 만들기]. 같은 구조가 반복되는 상자(AZ A·B)는 하나로 합쳐 ×2 를 붙이고,
    NAT 같은 보조 아이콘과 빈 상자는 빼고, 겹치는 상자(Auto Scaling)는 접어 이름에 적고, 세로로 쌓인 상자는 한 줄로 눕힙니다.
    슬라이드 한 칸(1/4)에 들어가는 요약 그림이 새 탭에 생기고 원본은 그대로입니다.
  - 여러 개를 선택하면 오른쪽 패널과 오른쪽 클릭 메뉴에 정렬(왼쪽·가운데·오른쪽·위·아래), 간격 맞추기, 크기 맞추기가 나옵니다.
    요소를 끌면 다른 요소의 가장자리·가운데에 맞춰 분홍 안내선이 보이며 붙습니다(보기 설정에서 끌 수 있음).
  - 팔레트 위쪽의 [글상자]와 [번호]로 설명 글과 ①②③ 흐름 번호를 넣습니다. 번호는 다음 수가 자동으로 붙습니다.
  - Ctrl+D 로 복제합니다. 그룹은 안의 요소와 그 사이 연결선까지 함께 복제됩니다.
  - Ctrl+F 로 캔버스 안에서 라벨·서비스 이름을 찾습니다. Enter 로 다음 결과로 이동합니다.
  - 저장·열기: JSON 그래프 파일을 사용합니다. 처음 저장할 때 위치를 고르고, 이후 Ctrl+S 는 같은 파일에 덮어씁니다.
    다른 이름으로 저장은 Ctrl+Shift+S (또는 저장 버튼 오른쪽 클릭), 열기는 Ctrl+O 입니다.
  - 탭을 닫으면 최근 10개까지 보관되며 Ctrl+Shift+T 또는 탭 오른쪽 클릭 [닫은 탭 다시 열기]로 되살릴 수 있습니다.

내보내기
  - [PNG 복사] 또는 Ctrl+C: PNG 가 클립보드에 복사되며, PowerPoint 에서 Ctrl+V 로 붙여 넣습니다. 선택한 것이 있으면 선택 영역만 복사합니다.
    글자를 선택한 상태에서는 Ctrl+C 가 글자 복사로 동작합니다.
  - [내보내기 ▾ > 내보내기 설정]: 배율(1~4배), 배경(투명·흰색), 여백, 16:9 슬라이드 맞춤, 제목, 범례(실선·점선 뜻)를 미리 보며 정합니다.
    PNG 복사도 이 설정을 따릅니다. EXE 에서 PNG·SVG 저장은 다운로드 폴더에 저장됩니다.
  - EXE 전용: Ctrl+Shift+C 또는 [내보내기 ▾ > 전체를 도형으로 복사]를 누르면 PowerPoint 에 편집 가능한 도형
    (1.5cm SVG 아이콘, 그룹 사각형, 도형에 붙는 연결선)으로 붙여 넣을 수 있습니다.

규칙 검사
  - 상단의 방패 [규칙 검사] 버튼(숫자 배지)에서 현재 위반 목록을 확인합니다. 항목을 클릭하면 해당 요소가 선택됩니다.
  - 심각도는 차단(빨강) · 경고(주황) · 참고 세 가지이며, 왜 문제인지 한두 문장으로 알려 드립니다.
    예: DB 를 Public subnet 에 두면 경고, VPC 에 인터넷 게이트웨이가 2개면 차단, Lambda → RDS 직접 연결은 경고(RDS Proxy 권장).
  - Delete 로 지울 때도 같은 규칙 검사를 거칩니다.
  - 잘못 놓인 요소 위에는 경고·차단 표시(!)가 늘 뜹니다. 보기 설정에서 숨길 수 있는 건 참고(i)뿐이며, 내보내기에는 어느 표시도 들어가지 않습니다.
  - 규칙은 data/rules.json 에 데이터로 들어 있어 쉽게 늘릴 수 있습니다.

가이드 (단계별로 만들기)
  - 빈 캔버스의 [따라 하기] 카드 또는 상단 [가이드]를 누릅니다. 만들 형태를 고르면 뼈대가 들어가고, 요건(멀티 AZ·WAF·CDN·암호화·DR·예산)을
    체크하면 그에 맞는 카드가 순서대로 나옵니다. 카드마다 이유 설명과 [넣기] 버튼이 있으며, 마지막은 규칙 검사 → AI 검수 → 내보내기입니다.
  - 중간에 닫아도 진행 상태가 남습니다. 숫자 점을 눌러 지난 단계로 돌아갈 수 있습니다.

AI 검수 · 그리기
  - 상단 칩에 현재 연결된 AI(Claude CLI / ChatGPT CLI / Claude / GPT)가 표시됩니다.
  - 상단 [AI 검수]: 제안서 컨텍스트(제목·요건서·제약)와 다이어그램을 함께 보내 요건 대비 빠진 것·과한 것을 핀으로 표시합니다.
  - 빈 캔버스의 "무엇을 그려 볼까요?" 칸 또는 [AI] 패널 › [말로 그리기]: 만들고 싶은 걸 막 적고 Enter(또는 [시작하기]). 팝업에서 AI 가 부족한 것만 쉬운 질문으로 묻고(최대 3개, "잘 모르겠어요"도 됨),
    그릴 내용을 먼저 보여 줍니다. [캔버스에 그리기]를 눌러야 그려지고 Ctrl+Z 로 되돌릴 수 있습니다. 정리된 상황(제목·요건·제약)은 파일에 같이 저장됩니다.
    익숙하면 [직접 적어서 그리기]에서 상황과 요청을 직접 적어도 됩니다.
    되돌리기가 가능하며, 규칙 검사를 통과해야 반영됩니다.
  - 처음 사용할 때 연결 안내가 4단계로 진행됩니다: 방식 선택 → 설정 → 연결 확인 → 완료. 완료되면 하던 작업을 이어서 합니다.
    · Claude CLI: 이 PC 에 설치된 claude 명령으로 실행하며 내 Claude 구독을 사용합니다(추가 비용 없음).
      먼저 터미널에서 `claude auth login` 을 실행해 로그인해 두어야 합니다.
    · ChatGPT (Codex CLI): 이 PC 에 설치된 codex 명령(OpenAI Codex CLI)으로 실행하며 내 ChatGPT 구독(Plus·Pro 등)을 사용합니다(추가 비용 없음).
      먼저 터미널에서 `npm i -g @openai/codex` 로 설치하고 `codex login` 으로 ChatGPT 계정에 로그인해 두어야 합니다.
    · Claude API 키 / OpenAI API 키: 키를 넣어 직접 호출합니다(토큰 비용 별도). 키는 내 Windows 계정으로 암호화해 data\secrets 에 저장합니다.
  - 웹 버전에서 CLI 쓰기: 웹은 준비돼 있고, 내 PC 쪽은 직접 합니다. Node.js 18+ 를 깔고 터미널에서
      curl -fsSLO https://svalu.github.io/arch-canvas/bridge.mjs && node bridge.mjs      (Windows PowerShell 은 iwr … -OutFile bridge.mjs; node bridge.mjs)
    를 실행한 뒤, 브리지 창에 뜬 6자리 연결 코드를 웹의 [AI 연결] 창에 넣습니다. 웹을 쓰는 동안 브리지 창은 켜 둡니다.
    브리지는 127.0.0.1 에서만 열리고 Arch Canvas 웹 주소에서 온 요청만 받습니다. 크롬·엣지를 권합니다.
  - 실패하면 쉬운 설명과 [다시 시도] 버튼이 표시되고, 기술 정보는 '상세 보기'에서 확인할 수 있습니다. 취소해도 다이어그램은 그대로입니다.
  - AI 결과는 요청한 탭에 들어갑니다. 기다리는 동안 다른 탭으로 옮겨도 섞이지 않습니다.
  - Claude CLI 는 이 앱 전용 설정으로 실행됩니다. 사용자의 Claude 설정·훅·MCP·CLAUDE.md 를 읽지 않고, 파일·명령 도구도 쓰지 않습니다.
  - Codex CLI 는 매번 빈 작업 폴더에서 읽기 전용(파일을 바꾸지 못하는) 모드로 한 번만 답하게 실행됩니다.
  - AI 를 쓰지 않는 환경이면 보기 설정(⚙)에서 [AI 기능 사용]을 끄십시오. AI 관련 버튼이 모두 숨겨집니다.

0.4 에서 바뀐 것
  - 복사·붙여넣기: 요소를 선택하고 Ctrl+C, 마우스를 둔 자리에 Ctrl+V. 다른 탭에도 붙일 수 있습니다. Ctrl+X 잘라내기.
    선택이 없을 때 Ctrl+C 는 그림(PNG) 복사입니다. 오른쪽 클릭 메뉴에도 복사·잘라내기·붙여넣기가 있습니다.
  - 화살표 키로 선택한 요소를 1px(Shift: 10px) 옮깁니다. 더블클릭 또는 F2 로 이름을 바꾸고, Esc 로 선택을 해제합니다.
  - 조각 템플릿: 자주 쓰는 묶음(예: 2-AZ 웹 계층)을 선택해 오른쪽 클릭 [조각 템플릿으로 저장]. 템플릿 메뉴 [내 조각]에서 고르면 지금 그림에 끼워 넣습니다.
    내 템플릿·조각은 메뉴에서 × 로 지울 수 있습니다.
  - 업데이트: 하루 한 번 새 버전을 확인해 상단에 [새 버전] 표시가 뜹니다. 누르면 변경 내용을 보고 [지금 업데이트]로 바로 바꿀 수 있습니다.
    도움말(?) 패널의 [업데이트 확인]으로 직접 확인할 수도 있습니다.

0.9.16 에서 바뀐 것
  - 개요도: DR·백업·스탠바이 같은 보조 환경 상자와, CloudWatch·CloudTrail·IAM 같은 관리·보안 서비스만 든 상자는
    상자 하나로 접고(이름에 서비스 이름을 적음) 선은 그 상자로 잇습니다. 큰 그림(NACS 46개)이 4089px → 3424px 폭으로 줄었습니다.
  - 자동 정렬: 상자 없이 아이콘만 든 줄도 빈 틈을 당겨 붙이고, 상자가 내용에 맞춰 커진 뒤 다시 겹치면 마지막에 비킵니다.
  - [이 답변대로 그림 고치기]: AI 가 자리 옮기기를 자동 정렬에 미루지 않고 직접 하도록 요청을 고쳤습니다
    (실제 Claude 로 NACS 그림에서 선 교차 100 → 69).

0.9.15 에서 바뀐 것
  - [물어보기] 답변 아래에 [이 답변대로 그림 고치기] 버튼이 생겼습니다. 누르면 답변의 제안을 그림 변경으로 바꿔 먼저 보여 주고,
    [캔버스에 그리기]를 누르면 옮기기·다시 잇기를 적용한 뒤 자동 정렬까지 합니다. Ctrl+Z 한 번이면 통째로 되돌아갑니다.

0.9.14 에서 바뀐 것

  - AI 가 좌표 없이 추가한 노드를 연결 관계에 따라 배치합니다. 흐름 사이에 끼우는 노드는 두 노드 사이 한 줄로, WAF 처럼 붙는 것은 위·아래로,
    S3·CloudFront 같은 리전·글로벌 서비스는 VPC 밖에, 그 밖의 것은 연결 상대가 있는 그룹 안 빈자리에 놓습니다. 자리가 좁으면 바깥 노드를 옆으로 밀어 공간을 만듭니다.

0.3 에서 바뀐 것
  - 정렬·간격·크기 맞추기, 끌 때 정렬 안내선
  - 글상자, ①②③ 번호
  - 내보내기 설정(배율·여백·16:9·제목·범례, 미리보기)
  - 캔버스 찾기(Ctrl+F), 그룹 통째 복제(Ctrl+D)
  - 파일 저장 위치 기억(Ctrl+S 덮어쓰기), 다른 이름으로 저장, 닫은 탭 다시 열기
  - AI 기능 끄기, 밝은 솔루션 구성도 템플릿
  - 탭 목록이 꼬이던 문제, AI 결과가 다른 탭에 들어가던 문제, 저장 누락, 규칙·템플릿 오류 등 다수 수정

0.2 에서 바뀐 것
  - 탭: 여러 다이어그램을 탭으로 열어 두고 오갈 수 있습니다. 더블클릭으로 이름 바꾸기, 끌어서 순서 바꾸기, 가운데 클릭으로 닫기를 지원하며 탭마다 따로 저장·되돌리기됩니다.
  - AI 연결: 상단 칩에 연결된 AI 가 표시되고, 누르면 4단계(방식 선택 → 설정 → 연결 확인 → 완료) 안내가 열립니다.
  - 프롬프트로 그리기: AI 패널의 그리기·고치기에 환경을 문장으로 적으면 빈 캔버스에도 리전·VPC·AZ·서브넷까지 겹치지 않게 자동 배치해 그립니다.
  - 물어보기: 경고·핀·선택한 요소 위의 [AI에게 물어보기]로 바로 질문할 수 있습니다.
  - 다크 모드: 화면 전체(툴바·패널·메뉴·창 제목줄)가 한 톤으로 바뀌며 부드럽게 전환됩니다.
  - 카드 모드: 솔루션 구성도처럼 카드·섹션으로 그릴 수 있습니다.
  - 보기 설정(⚙): 격자 선·점과 진하기(0이면 없음)·간격, 텍스트 크기, 연결선 기본 모양, 그림자, 핀 표시 끄기(제안서 화면용)를 설정합니다.
  - 처음 실행하면 둘러보기 투어가 나옵니다. 도움말(?)에서 다시 볼 수 있습니다.
