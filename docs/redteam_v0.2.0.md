## P3. 규칙 · 템플릿이 AWS 관점에서 틀림

- Lambda 를 프라이빗 서브넷에 두면 경고가 뜨는데, 팔레트 추천은 바로 그걸 권함. VPC 연결 Lambda 는 서브넷에 그리는 게 맞음.
- "Lambda → RDS 직접 연결" 규칙이 RDS Proxy 에도 걸림. 규칙이 권하는 해결책을 경고함. DB 관련 규칙 여러 개가 Proxy 를 DB 로 봄.
- DAX, Route 53 Resolver, S3 Access Point 같은 VPC 안 리소스를 "리전 서비스"로 잘못 경고.
- 인증 사용자 아이콘(Authenticated-User)은 사용자 규칙에서 빠짐.
- IGW 를 VPC 경계에 걸쳐 그리고 VPC 에 연결하면 차단 → 패치 전체가 거부됨.
- 07 하이브리드: Customer Gateway → Direct Connect 로 연결 (CGW 는 VPN 전용). 단일 AZ.
- 05 ECS / 06 EKS: 프라이빗 서브넷인데 NAT·VPC 엔드포인트·IGW 없음, ALB 가 퍼블릭 서브넷 밖, 한쪽 AZ 만 연결.
- 02 3티어: NAT 게이트웨이 2개가 아무것도 연결 안 됨, 동기 복제 선이 양방향 화살표.
- 08 솔루션 다크: 특정 고객 건(Amazon Connect, Live Sync 등) 같은 문구가 그대로 있어 다른 제안서에 새어 나갈 위험.

## P4. 문구 · 용어

- 반말→존댓말 일괄 치환 흔적: "사현재 데이터센터"(→사내), "아니입니다"(→아닙니다), "뭘 만들 것입니다?", "뭐가 문제입니다?", "어떻게 고치면 좋습니다?".
- 앱이 하는 일을 사용자에게 부탁하는 말투로 씀: "알려 주세요", "짚어 주세요", "돌려주세요" → "알려 드립니다" 등.
- 투어 밖에 남은 반말: guide.json("켜.", "넣어.", "골라."), rules.json("나눠.", "그려."), providers.js("막혔어."), ui.jsx("적용했어", "물어봐도 돼").
- 문서에 없는 버튼 이름: "[넣어줘]"(실제는 "넣기"), 도움말의 "상단 [검수]"(실제는 방패 버튼).
- 용어가 섞임: 규칙 검사 / 검수 / 핀 / 배지, 심각도 "막음 / 막았습니다 / 문제". → 규칙 검사(방패), AI 검수, 차단/경고/참고 로 통일 제안.
- 내부 id·개발 용어 노출: "연결선 n3 → n5", AI 그리기 미리보기의 `add_node Arch_Amazon-CloudFront`, "id: n3 · in vpc", "block/warn".
- 사용안내.txt: 연결 단계 3단계/4단계 혼재, 로그인 명령 `claude` vs `claude auth login` 혼재.

## 개선 아이디어 (버그 아님)

- 내보내기 대화상자: 배율 1~4배, 제목·범례(실선/점선 의미), 여백, 16:9 맞춤.
- 정렬·간격 맞추기·스마트 가이드 (지금은 4px 격자뿐).
- 인프라 모드 자유 텍스트, ①②③ 번호 배지, 캔버스 안 찾기(Ctrl+F).
- AI 없는 사람용 "AI 사용 안 함" 설정 (사내 PC 에서 API 막힌 경우).
- 다른 이름으로 저장, 같은 파일 덮어쓰기, 닫은 탭 다시 열기.
- 밝은 범용 솔루션 템플릿.

## 문제없다고 확인된 것

- 탭 전환과 자동 저장 경쟁 없음, 되돌리기 기록 탭별 분리, 마지막 탭 닫기 정상.
- useExit 닫힘 애니메이션 중 다시 열기 정상, 설정 팝오버 안 클릭/슬라이더로 안 닫힘.
- AI 답변은 텍스트로만 렌더링 (XSS 없음), 색상값 검증으로 SVG/PPT 주입 없음, 아이콘 SVG 는 스크립트 실행 불가.
- secrets 이름 경로 조작 불가, API 키가 로그·저장 JSON 에 안 들어감.
- 한글·공백 경로 정상, 960px 폭 툴바 정상, 2300개 ops 337ms.
