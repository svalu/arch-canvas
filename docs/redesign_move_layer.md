# 이동 · 상자 · 레이어 재설계안 (0.5.0 레드팀 결과)

레드팀 4명: 직접 조작해 본 사용성 테스터, 코드 리뷰어, 파워포인트·피그마 사용자 관점, AWS 아키텍처 관례.
동료 피드백(박민석): 선이 움직이지 않음 · 연결한 선을 다른 데로 못 바꿈 · 글상자 넣는 법을 모름.

## 1. 한 문장 진단

"무엇이 상자 안에 있는가"를 정하는 기준이 두 개라서 화면과 실제가 어긋난다.

- 숨은 기준: 부모-자식 트리. 무엇이 함께 움직이는지, 상자 앞뒤 순서를 정한다.
- 보이는 기준: 화면 위치. 놓을 자리, 규칙 검사를 정한다. 그런데 판정점이 세 가지(아이콘 가운데, 상자 왼쪽 위+8px, 붙여넣기 왼쪽 위+1px)이고 "나중에 그린 상자가 이긴다".
- 둘을 맞춰 주는 장치가 없다. 그래서 상자를 끌면 사용자가 몰랐던 "안의 것"이 따라오고, 반대로 안에 있어 보이는데 안 따라오기도 한다.

## 2. 사용자가 겪는 문제 (심각한 순)

| # | 문제 | 누가 찾음 |
|---|---|---|
| 1 | 상자를 선택하면 앞뒤 순서가 바뀐다 (선택된 상자가 +1000 으로 떠서 ASG 가 서브넷 뒤로 숨음) | 테스터·코드 |
| 2 | "맨 앞으로"가 같은 부모 안에서만 동작해서 겹친 다른 상자보다 앞으로 못 감 | 테스터·코드 |
| 3 | 놓을 때 소속이 조용히 바뀜. 끄는 동안 어느 상자로 들어가는지 표시가 없음 | 전원 |
| 4 | 3티어 템플릿의 EC2 가 서브넷이 아니라 오토 스케일링 그룹의 자식 → AZ·서브넷을 옮기면 EC2 가 남음 | AWS·코드 |
| 5 | 아이콘 아래 라벨을 잡으면 아이콘이 아니라 바깥 상자가 끌림 | 테스터 |
| 6 | Ctrl+G 가 파워포인트 그룹이 아니라 "그룹"이라는 새 상자를 만들고, 다른 AZ 의 것까지 한 서브넷으로 끌어옴 | 테스터·모델·코드 |
| 7 | 상자 안 빈 곳을 클릭해 끌면 상자 전체가 움직임 (상자만 옮기는 Alt 는 아무 데도 안 보임) | 테스터·동료 |
| 8 | Shift+드래그 영역 선택이 상자 위에서 시작이 안 됨 | 테스터 |
| 9 | 상자를 내용보다 작게 줄일 수 있고, 내용이 삐져나와도 소속은 그대로 | 테스터·코드 |
| 10 | 상자 테두리로 크기를 바꾸려다 연결선이 생김 (연결 점과 크기 손잡이가 겹침) | 테스터 |
| 11 | 연결선 끝을 다른 노드로 옮길 수 없음 · 꺾이는 위치를 바꿀 수 없음 | 동료 |
| 12 | 글상자 넣는 법을 못 찾음 (오른쪽 클릭엔 "섹션 추가"만 눈에 띔) | 동료 |
| 13 | 레이어 패널이 실제 그리는 순서와 다르게 보임, 이름이 잘려 AZ A/B 구분 불가 | 테스터·코드 |
| 14 | 잠금이 끌기만 막음 (화살표 이동·정렬·크기 조절·삭제는 됨), 캔버스에 잠금 표시 없음 | 코드·테스터 |
| 15 | PowerPoint 로 붙이면 상자와 아이콘이 따로 놀아 캔버스와 반대로 동작 | 모델 |

바로 고칠 수 있는 버그(설계와 무관): Alt-끌기 뒤 소속 재계산 누락, 레이어 패널에서 자기 안으로 넣으면 순환, 화살표 이동이 부모·자식을 겹쳐 이동(Ctrl+A 후 화살표 시 찢어짐), 크기 조절이 규칙 검사를 건너뜀.

## 3. 재설계 방향 (추천)

**원칙: 보이는 대로가 사실이다. 소속은 화면 위치로만 정하고, 앞뒤 순서는 소속과 따로 하나로 관리한다.**

### 상자를 두 종류로 나눈다 (AWS 관례)

| 종류 | 예 | 안의 것 | 끌면 |
|---|---|---|---|
| 담는 상자 | Region, VPC, AZ, 서브넷, 사내 데이터센터, AWS 계정, 섹션 | 그 안에 놓인 것이 속함 | 안의 것과 함께 이동 |
| 겹치는 상자 | 오토 스케일링 그룹, 보안 그룹, ECS 클러스터·노드 그룹, 스팟 플릿 | 아이콘은 서브넷에 속한 채로 "멤버"만 됨 | 테두리만 이동 (멤버를 감싸도록 자동 맞춤 선택 가능) |

이렇게 하면 EC2 는 늘 서브넷에 속하고, ASG 는 두 AZ 를 가로질러 그려도 아무것도 빼앗지 않는다.

### 사용자에게 보이는 규칙 (안내 문구 그대로)

1. 아이콘은 가운데가 놓인 가장 작은 담는 상자에 속합니다.
2. 상자는 자기를 완전히 감싸는 가장 작은 담는 상자에 속합니다.
3. 끄는 동안 들어갈 상자에 테두리가 켜지고 "→ Private subnet (App)"처럼 이름이 뜹니다.
4. 상자를 끌면 그 안에 보이는 것이 함께 움직입니다. 상자만 옮기려면 Alt 를 누른 채 끕니다. (끄는 동안 안내에 표시)
5. 상자 소속이 바뀌면 알림이 뜨고 Ctrl+Z 로 되돌릴 수 있습니다.
6. 앞뒤 순서는 화면 전체에서 하나입니다. Ctrl+] / Ctrl+[ 로 바꾸고, 선택해도 순서는 바뀌지 않습니다.
7. 기본 배치: 바깥 상자 → 안쪽 상자 → 겹치는 상자 → 연결선 → 아이콘 → 번호. "맨 앞/맨 뒤"는 같은 띠 안에서 움직입니다. (ASG 가 서브넷 채움 뒤로 숨는 일 없음)
8. Ctrl+G 는 파워포인트처럼 보이지 않는 묶음을 만들고 Ctrl+Shift+G 로 풉니다. 지금의 Ctrl+G(새 상자로 감싸기)는 [상자로 감싸기]로 이름을 바꾸고, 선택한 것들의 공통 상위 상자 안에 만듭니다.
9. 잠근 것은 어떤 방법으로도 움직이거나 크기가 바뀌지 않고, 캔버스에 자물쇠가 보입니다. 잠근 상자 안을 끌면 화면이 이동합니다.
10. 상자는 안의 것보다 작게 줄일 수 없습니다.

### 선(연결선)

- 선을 선택하면 양 끝에 손잡이가 생기고, 끌어서 다른 노드에 놓으면 연결 대상이 바뀝니다.
- 직각선은 가운데 손잡이를 끌어 꺾이는 위치를 옮깁니다. PowerPoint 로 보낼 때도 같은 위치(연결선 조정점)로 갑니다.
- 상자 테두리의 연결 점은 마우스를 올렸을 때만, 크기 손잡이와 겹치지 않는 곳에 보입니다.

### 화면 정리

- "그룹"이라는 말은 파워포인트 묶음에만 쓰고, AWS 상자는 "상자"로 부릅니다.
- 레이어 패널은 실제 그리는 순서 그대로(위가 앞) 한 줄 목록으로 보여 주고, 소속은 회색 꼬리표("· Private subnet (App) · AZ A")로 표시합니다. 이름 잘림 없앰, 잠금 상태 항상 표시.
- 아이콘 라벨도 아이콘을 잡는 영역에 포함합니다.
- 빈 캔버스 오른쪽 클릭 맨 위에 [글상자 추가], 툴바에도 [T] 버튼.
- Shift+드래그는 상자 위에서도 영역 선택. Shift+클릭만 하나씩 더하기·빼기.

## 4. 진행 순서 제안

| 단계 | 내용 | 크기 |
|---|---|---|
| 1 | 바로 고칠 버그 4개 + 선 끝 옮기기 + 글상자 찾기 쉽게 + 선택 시 순서 고정 + 라벨 잡기 | 작음, 바로 배포 |
| 2 | 담는/겹치는 상자 구분, 소속을 화면 위치로 일원화, 끄는 동안 들어갈 상자 표시, 템플릿(02·05) 이전 | 큼, 핵심 |
| 3 | 앞뒤 순서 하나로 + 띠, Ctrl+G 파워포인트식 묶음, 레이어 패널 개편, 잠금 강화 | 중간 |
| 4 | 직각선 꺾임 위치 조절(캔버스 + PowerPoint), 상자 최소 크기 | 중간 |

데이터 변경: 겹치는 상자에 `members` 목록, 그래프에 `groupSets`(Ctrl+G 묶음). 기존 파일은 열 때 자동으로 바꿔 줌(EC2 를 ASG 에서 서브넷으로 옮기는 등).
