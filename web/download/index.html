설치

  1. zip 을 원하는 폴더에 풉니다.
  2. Arch Canvas.exe 를 실행합니다. 처음 실행하면 같은 폴더에 data 폴더가 생깁니다.
  3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.

Windows 버전에서만 되는 것

  1. PowerPoint 에 편집 가능한 도형으로 붙여 넣기 (Ctrl+Shift+C)
  2. 내 PC 의 Claude CLI 로 AI 검수·그리기 (내 Claude 구독 사용)
  3. 앱 안 [업데이트] 버튼으로 새 버전 받기
Windows 10/11 · WebView2 런타임 필요 (Windows 11 기본 포함). 이전 버전과 변경 내역은 릴리스 목록에 있습니다.
