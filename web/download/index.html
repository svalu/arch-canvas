처음 써 보는 분처음 설치하기
  1. 위의 Windows 버전 다운로드를 눌러 zip 파일을 받아요.
  2. 받은 zip 을 원하는 폴더에 압축 풀기 해요. 설치는 없어요.
  3. Arch Canvas.exe 를 더블클릭해요. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요.
  4. 처음 켜면 화면 안내가 나와요. 빈 캔버스의 말로 그리기로 바로 시작해 보세요.
이미 쓰고 있는 분새 버전으로 업데이트
  1. 앱을 켜면 위쪽에 주황색 [업데이트] 버튼이 떠요. 누르면 바뀐 내용을 보고 바로 업데이트돼요.
  2. 안 보이면 ? (도움말) → 업데이트 확인을 눌러요. 확인은 하루 한 번 자동으로 해요.
  3. 새로 받아서 쓰고 싶으면 zip 을 받아 원래 폴더에 덮어쓰기 해도 돼요. 옆의 data 폴더는 그대로 두세요.

AI 기능은 내 PC 의 Claude CLI(내 Claude 구독)나 ChatGPT CLI(내 ChatGPT 구독), 또는 API 키로 연결해요. 연결은 앱 안에서 4단계로 안내해 드려요.

자주 묻는 질문

여기서 먼저 확인해 보세요.

설치 없이 바로 써 볼 수 있나요?

네. 웹 버전을 열면 브라우저에서 바로 쓸 수 있어요. 맥에서도 돼요.

다만 웹 버전은 PowerPoint 편집 도형 복사와 Claude CLI 연결이 안 되고(PNG 복사는 돼요), 작업이 그 브라우저에만 저장돼요.

"Windows의 PC 보호" 창이 떠요.

처음 받은 프로그램이라 Windows 가 한 번 확인하는 화면이에요. 추가 정보를 누르면 나오는 실행 버튼을 누르세요.

회사 PC 에서 아예 막힌다면 보안 정책 때문일 수 있어요. 그럴 땐 웹 버전을 쓰세요.

업데이트하면 내 그림이 사라지나요?

아니요. 그림은 EXE 옆 data 폴더에 남아 있어요. 중요한 그림은 Ctrl+S 로 파일로도 저장해 두세요.

AWS 를 전혀 몰라도 쓸 수 있나요?

네. 말로 그리기에 만들고 싶은 걸 막 적으면, AI 가 몇 명이 쓰는지·계속 켜 둘지 같은 걸 쉬운 질문으로 묻고 그려 줘요. 이미 만든 프로그램이 있으면 쓰시는 AI 로 뽑은 시스템 설명 문서(MD)를 넣어도 돼요.

AI 는 무엇으로 연결하나요? 돈이 드나요?

내 PC 에 설치된 Claude CLI 나 ChatGPT 의 Codex CLI 를 쓰면 내 구독(Claude 또는 ChatGPT)으로 동작해서 추가 비용이 없어요. Claude·OpenAI API 키를 넣어 쓸 수도 있어요(이 경우 사용량만큼 요금).

AI 를 안 쓰면 보기 설정에서 끌 수 있고, 그리기·내보내기는 그대로 돼요.

내 그림이 어디로 보내지나요?

그림은 내 PC(또는 내 브라우저)에만 저장돼요. AI 기능을 쓸 때만 그 요청에 필요한 그림 설명이 연결한 AI 로 가요. 의견 보내기는 내가 적은 내용과 버전 정보만 보내요.

PowerPoint 에는 어떻게 붙이나요?

Windows 버전에서 Ctrl+Shift+C 를 누르고 PowerPoint 에서 Ctrl+V 하면 아이콘·상자·연결선이 편집 가능한 도형으로 붙어요. 그림으로 붙이려면 Ctrl+C (PNG).
